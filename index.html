一个窗口，投屏与文件管理

ScrcpyX 把安卓手机画面投到 Windows 桌面上，投屏和文件管理都在同一个窗口里完成。画面由 adb 启动的 scrcpy-server 提供，解码与显示由程序本身完成。

下载最新版本 查看源码

版本发布在 GitHub Releases 中提供安装包（ScrcpyX-Setup-*.exe）与 zip 包。

功能

同一窗口

首页与投屏视图切换，不再弹出第二个窗口。左侧是操作栏，中间是手机画面。

文件管理

浏览手机存储，支持复制、剪切、粘贴、导入、导出、新建、重命名与删除。文件面板竖屏在右侧、横屏在下方展开。

参数精简

首页只保留常用的 5 个参数：最大画面尺寸、最大帧率、视频比特率、保持唤醒、关闭屏幕。其余 scrcpy 参数暂未接入。

延迟可见

左栏底部显示渲染耗时与 ADB 往返耗时，方便判断当前的流畅程度。注意：这不是端到端延迟。

系统要求

  • Windows 10 1809 及以上，或 Windows 11，x64。
  • .NET 10 桌面运行时。
  • Windows App Runtime 1.8。
  • 安卓手机，开启 USB 调试；无线连接需要先执行一次 adb connect。

程序启动时会检查以上运行时。缺少时会自动打开对应的下载页。

安装

  1. 到 Releases 下载 ScrcpyX-Setup-*.exe，按向导安装。安装到当前用户目录，不需要管理员权限。
  2. 或下载 zip 包，解压后直接运行 ScrcpyX.exe。
  3. 用数据线或无线调试连接手机，在首页点「开始投屏」。

常见问题

为什么首页看不到手机？

确认手机已开启 USB 调试并允许此电脑调试。无线连接需要先执行一次 adb connect <手机地址>，然后刷新设备。

投屏中为什么不能切换设备或修改参数？

参数在投屏前确定，投屏中切换会让画面与设置不一致。停止投屏后再开始，新参数才会生效。

是官方产品吗？

不是。ScrcpyX 是独立项目，底层使用官方 scrcpy 4.1 的 server 与 adb，见 GitHub 仓库的第三方组件说明。
