# ScrcpyX

ScrcpyX 在 Windows 上用同一个窗口把安卓手机画面投出来。它通过 adb 把 scrcpy-server 推到手机并启动，自己解码 H.264，画面画在这个窗口里的位图上。

没有音频，没有录屏，也没有场景方案。没有第二个投屏窗口。

## 使用

解压后运行 `ScrcpyX.exe`。程序使用同目录的 `DLL\adb.exe` 和 `DLL\scrcpy-server`。设置和窗口位置写在 `data`。`data` 不可写时会拒绝启动。

- 连上手机并打开 USB 调试，在首页点「开始投屏」。投屏前可以选设备，并改高级选项。
- 投屏后还是这个窗口。左侧有「停止投屏」「返回」「主页」「任务」「文件」。中间是手机画面，可以点按。黑边不发给手机。
- 手机画面按宽高比显示，不超过 1 倍原始分辨率，也不超出当前工作区。拖窗口边缘时，画面保持宽高比。
- 竖屏时「文件」在右侧展开，宽 360 DIP，窗口向右变宽，左边缘先不动。横屏时面板在下方展开，高 320 DIP，窗口只向下变高。放不下时先把窗口移进工作区，仍放不下再缩小手机画面，面板尺寸不变。面板里可以进入目录、向上、复制、新建、重命名和删除。收起后再展开，还停在刚才的目录。
- 投屏时不能切换设备，也不能改参数。停止之后再开始，新参数才会生效。
- 「高级选项」只有五项：最大画面尺寸、最大帧率、视频比特率、保持设备唤醒、启动后关闭设备屏幕。尺寸、帧率和码率留空时用默认值。
- 首页的「文件」可以查看手机存储，并在电脑和手机之间复制、新建文件夹、重命名和删除。

关闭窗口时会停止投屏。

## 开发与验证

需要 Windows 10/11 x64 和 .NET 10 SDK。界面是 WinUI 3，发布为免安装自包含包。版本号 0.4.0。

```powershell
dotnet build .\src\ScrcpyX\ScrcpyX.csproj -c Release
dotnet run --project .\tests\ScrcpyX.SelfTest\ScrcpyX.SelfTest.csproj -c Release
.\Publish.ps1
```

参数清单在 `DLL\scrcpy-options.json`，共 99 项、13 个分组。界面只接入上面的 5 个参数。
